Bienvenue sur Figurine Store

Cette page est la version statique pour GitHub Pages.

Le site complet (panier, compte, base de données) est une application PHP + MySQL. GitHub Pages ne peut pas exécuter PHP.

Pour utiliser le site en entier : hébergez le projet sur un serveur PHP (WAMP en local, ou un hébergeur comme o2switch, o2switch, InfinityFree, 000webhost, etc.) et ouvrez index.php.
